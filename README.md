
# yudou-node-crawler —— 玉豆节点自动化获取工具

> 高效、鲁棒、自适应的某豆加密免费节点订阅采集器

## 概述

`cawling_yudou_Nodes.py` 是一套专为[玉豆](https://www.yudou789.top/)设计的智能爬虫脚本，能够自动定位每日发布的“免费精选节点”文章，解析其中的节点订阅链接（`.txt`），并归档为本地文件。通过 **多级回退机制** 与 **启发式解析策略**，在网站结构波动或更新延迟时仍可保持高可用性。

## 核心特性

- **双引擎文章定位**  
  - **静态推算引擎**：基于已知基准映射（日期 → 文章ID）进行直接计算，毫秒级定位，无页面依赖。  
  - **动态解析引擎**：若推算失效，自动切换至首页 DOM 分析，通过标题日期间隔匹配最新文章。
- **密码自适应提取**  
  - 优先从 `data-secret` 属性进行 Base64 解码及常用密码字典碰撞；  
  - 回退至正则表达式深度扫描（支持“密码：”、“key=”等多种模式）。
- **订阅链接精准捕获**  
  - 基于 `.txt` 后缀的链接抽取，支持相对路径自动补全；  
  - 当 `<a>` 标签缺失时，采用全页面正则扫描作为补救。
- **无感知日期容错**  
  - 默认拉取当日文章，若目标缺失则自动降级至昨日内容，确保始终获取最新有效订阅。
- **持久化归档**  
  - 按 `nodes_YYYYMMDD.txt` 格式命名，存储于脚本所在目录，便于后续集成。

## 设计细节

### 日期→ID 映射模型

基于观察到的线性规律：

- 基准点：`(date=2026-05-10, id=865)`  
- 增量：`Δid = Δdays × 5`

公式：  
`target_id = base_id + (target_date - base_date).days × 5`

> 注：基准参数可根据网站实际调整周期在脚本头部常量中修改。

### 密码提取优先级链

1. `data-secret` → Base64 解码  
2. 内置 100 种常用 4 位密码编码碰撞  
3. 正则匹配（8 种常见模式）
