# 雨都免费节点爬虫 (cawling_yudou_Nodes.py)

自动抓取 [雨都](https://www.yudou789.top/) 网站每日发布的“免费精选节点”文章，提取其中的节点订阅链接（`.txt` 文件）并下载保存到本地，文件名包含发布日期。

## 功能特性

- 自动访问雨都首页，查找标题包含“免费精选节点”且日期为当日或昨日的文章链接。
- 若未找到当日/昨日文章，则回退到任意一篇包含“免费精选节点”的文章。
- 解析文章内容，尝试从 `data-secret` 属性或正则匹配获取解压密码（4位数字），但**当前版本仅下载原始 `.txt` 文件，未使用密码解密**（保留密码提取逻辑备用）。
- 在文章正文中查找 `.txt` 文件的下载链接，支持相对路径自动补全。
- 下载 `.txt` 文件内容，并以 `nodes_YYYYMMDD.txt` 格式保存到脚本所在目录。

## 依赖环境

- Python 3.6+
- 需要安装以下第三方库：
  - `requests`
